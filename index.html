⚠️ Firebase sozlanmagan

Bu ilova endi haqiqiy video-serverga (Firebase) ulanadi. Ishga tushirish uchun quyidagi qadamlarni bajaring:

  1. console.firebase.google.com saytiga kiring, yangi loyiha (project) yarating.
  2. Chap menyudan Firestore Database ni yarating (test mode).
  3. Chap menyudan Storage ni yarating (test mode).
  4. Loyiha sozlamalaridan (⚙️ → Project settings → General → Your apps → Web app) firebaseConfig obyektini nusxalab oling.
  5. Shu HTML fayldagi const firebaseConfig = {...} qismiga joylashtiring.

Bu bepul (Spark) tarifda ham ishlaydi.
